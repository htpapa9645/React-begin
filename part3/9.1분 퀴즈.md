13.다음 코드에서 props를 구조 분해 할당하려 합니다. 올바르게 작성한 코드는?

```javascript
function User(props: {name: string, age: number}){
    return(
        <>
            <p>name: {props.name}</p>
            <p>age: {props.age}</p>
        </>
    );
}
```

1. Function User(props: {name, age})
2. Function User({...props}: {name: string, age: number})
3. Function User({name, age}: {name:string, age: number})
4. Function User([name, age]: {name:string, age: number})

15.다음 코드를 실행한 결과로 알맞은 것은 무엇인가요?

```javascript
function User({children}: {children: React.ReactNode}){
    return <div>{children}</div>;
}
export default function App(){
    return(
        <User>
            <p>안녕하세요</p>
            <p>리액트를 공부 중입니다</p>
        </User>
    );
}
```

1. props.children은 배열이므로 타입 오류가 발생한다.
2. `<p>안녕하세요!</p><p>리액트를 공부 중입니다.</p>가 랜더링된다.`
3. `<p>리액트를 공부 중입니다.</p>만 <div>안에 랜더링된다.`
4. `children속성은 여러 요소를 가질 수 없으므로 오류가 발생한다.`
