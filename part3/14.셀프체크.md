# 아래 요구사항을 참고하여 간단한 리액트 애플리케이션을 만들어 보자.

## 요구사항

1. 버튼(button)을 랜더링하는 Button 컴포넌트를 만든다.
2. Button 컴포넌트에는 버튼의 내용과 이벤트 핸들러를 전달한다.
3. Button 컴포넌트는 부모 컴포넌트에서 전달한 내용과 이벤트 핸들러를 받아 내용은 랜더링하고 이벤트 핸들러는 클릭 이벤트 속성에 할당한다.
4. 버튼을 클릭하면 부모 컴포넌트에서 전달받은 이벤트 핸들러가 실행된다. 이벤트 핸들러의 로직은 자유롭게 구현한다.
