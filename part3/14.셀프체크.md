# 아래 요구사항을 참고하여 간단한 리액트 애플리케이션을 만들어 보자.

## 요구사항

1. 버튼(button)을 랜더링하는 Button 컴포넌트를 만든다.
2. Button 컴포넌트에는 버튼의 내용과 이벤트 핸들러를 전달한다.
3. Button 컴포넌트는 부모 컴포넌트에서 전달한 내용과 이벤트 핸들러를 받아 내용은 랜더링하고 이벤트 핸들러는 클릭 이벤트 속성에 할당한다.
4. 버튼을 클릭하면 부모 컴포넌트에서 전달받은 이벤트 핸들러가 실행된다. 이벤트 핸들러의 로직은 자유롭게 구현한다.

vite-react-event-selfcheck 에 예제 실습해보기

내가 직접 해본 예제

```javascript
// App.tsx
import Button from "./components/Button";

export default function App(){
  const onClickHandle = ({msg} : {msg: string}) => {
    alert(msg);
  };
  return(
    <>
      <Button onClickHandle={() => { onClickHandle({msg: '클릭됐슈'})}} />
    </>
  );
}

// Button.tsx
export default function Button({onClickHandle} : {onClickHandle: () => void}){
    return (
        <button onClick={onClickHandle}>클릭해봐유</button>
    );
}
```

책에서 의도한 예제풀이

```javascript
// App.tsx
/**
 * Button 컴포넌트를 import 한 뒤, 버튼을 클릭했을 때 실행할 함수를 handleClick이라는 속성으로 전달한다.
 * 이때 Button 컴포넌트는 html 의 시작 태그와 종료 태그처럼 사용해 버튼 내부에 표시할 내용을 children 으로 전달한다.
*/
import Button from '/components/Button';

export default function App(){
    return(
        <>
            <Button handleClick={() => alert('login');}>login</Button>
            <Button handleClick={() => alert('logout');}>logout</Button>
        </>
    );
}

// Button.tsx
/**
 * Button 컴포넌트에서는 부모 컴포넌트에서 전달한 children과 handleClick을 받아 <button> 요소에 적용한다.
 * children은 버튼 내부에 표시할 내용이고, 타입은 React.ReactNode로 저장한다.
 * handleClick은 클릭 이벤트 핸들러이고, 타입은 () => void 이다.
*/
export default function Button({
    children,
    handleClick,
} : {
    children: React.ReactNode,
    handleClick: () => void
}){
    return <button onClick={handleClick}>{children}</button>
}

```
