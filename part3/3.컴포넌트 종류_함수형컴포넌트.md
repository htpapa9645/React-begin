[함수형 컴포넌트]

>함수형 컴포넌트는 함수를 사용해 컴포넌트를 작성하는 방식이다.
function 키워드로 함수를 선언 한 뒤, return문 안에 jsx를 사용해 화면에 표시할
ui 구조를 정의한다.
함수형 컴포넌트가 실행되면 return 문에 작성한 jsx가 반환된다.
리액트는 반환된 jsx를 html로 변환해 웹 브라우저에 랜더링한다.

형식)
export default funciton [컴포넌트 이름](){
	return(...); // jsx 반환
}

함수형 컴포넌트의 이름은 "파스칼 케이스"로 작성해야 한다. 이는 리액트가 해당 함수를 일반 html태그가 아닌 컴포넌트로 인식하는데 필요하다.
******* "파스칼 케이스"란 각 단어의 첫 글자를 대문자로 쓰고, 공백이나 구분자 없이 이어 붙이는 표기법 *******

코드예제 실행) ~/part3/vite-react/src/App.tsx 참고

*함수형 컴포넌트는 클래스 컴포넌트보다 문법이 간결하고 직관적이다.
상속이나 복잡한 구조 없이 함수 하나만으로 컴포넌트를 만들 수 있어 가독성이 뛰어나고 작성하기도 쉽다.
