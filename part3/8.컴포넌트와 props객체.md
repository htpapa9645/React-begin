# 컴포넌트와 props 객체

- 리액트에서는 부모 컴포넌트가 자식 컴포넌트에 데이터를 전달할 수 있다.
  이때 사용하는 것이 "props"다

## props 객체란

- props(properties)는 컴포넌트를 마치 html 태그처럼 사용해 값을 속성 형태로 전달한다.\
  예를 들어, App 컴포넌트에서 User 컴포넌트로 **"철수"** 라는 데이터를 전달하려면 아래와 같이 코드를 작성한다.

```javascript
import User from "./components/User";
export default function App() {
  return <User name="철수" />;
}
```

위의 코드에서 <User name='철수' /> 는 User 컴포넌트를 화면에 랜더링하면서 `name`이라는 속성의 값으로 **철수**를 함께 전달한다.

만약? 여러개의 데이터를 전달하고 싶다면 아래와 같이 한다.

문자열은 `더블따옴표 " 또는 싱글따옴표 ' 로, 숫자나 표현식은 중괄호 {} ` 로 감싸 전달한다.

```javascript
import User from "./components/User";

export default function App() {
  return <User name="철수" age={20} />;
}
```

리액트에서는 부모 컴포넌트가 자식 컴포넌트에 전달한 모든 속성을 하나의 객체로 모아서 자식 컴포넌트로 전달한다.\
부모 컴포넌트에서 User 컴포넌트에 name과 age를 전달하더라도 리액트 내부에서는 이 데이터를 아래와 같이 단일 객체 형태로
전달한다.

```javascript
{
    name: '철수',
    age: 20
}
```

이 객체를 **props객체** 라고 한다.
즉, props 는 부모 컴포넌트가 자식 컴포넌트에게 넘겨주는 모든 데이터가 담긴 객체이다.

자식 컴포넌트는 전달받은 props 객체를 함수의 매개변수로 받는다.
매개변수의 이름은 props를 사용하지만, 꼭 정해진 건 아니며 다른 이름을 사용할 수도 있다.

User 컴포넌트에 어떤 값이 전달되는지 확인해 보자.

위에서 실행해서 살펴본 것처럼 자식 컴포넌트는 props 객체를 통해 부모 컴포넌트가 전달한 데이터를 받아 사용할 수 있다.\
props는 객체이기 때문에 자식 컴포넌트에서는 객체 형식으로 접근해야 한다.

자바스크립에서는 props에 타입을 지정하지 않아도 실행에는 문제는없다. 다만 **_타입스크립트_** 에서는 props 객체의 구조와 타입을 명확히\
지정해주는것이 좋다.\
타입을 지정하지 않으면 코드 에디터의 자동 완성 기능이나 오류 감사가 제대로 동작하지 않을 수 있다.

> User 컴포넌트의 코드를 아래와 같이 수정한다.

```javascript
export default function User(props: { name: string; age: number }){ // 1)
    return ( // 2)
        <>
            <p>name: { props.name }</p>
            <p>name: { props.age }</p>
        </>
    );
}
```

1.props의 타입을 명시합니다. 이 객체는 name(문자열)거ㅣ age(숫자) 속성을 가져야 한다.\
잘못된 타입을 전달하면 **_타입스크립트_** 가 컴파일 시점에 오류를 알려준다.

2.속성에는 props.name, props.age 처럼 점 표기법을 사용해 접근한다.\
props는 객체이므로 해당 키를 통해 값을 꺼내 사용하는 방식이다.\
이렇게 하면 오류 없이 User 컴포넌트에 전달된 데이터를 사용할 수 있다.

```plaintext
리액트에서 데이터를 전달할 때 부모 컴포넌트는 데이터를 props로 전달한다고하고 자식 컴포넌트는 props를 받아 사용한다고 한다.
```

## props 객체 타입 알아내기

> 리액트에서는 컴포넌트로 전달할 데이터 개수에 제한이 없다.\
> 즉, 개발자가 원한다면 10개든 100개든 얼마든지 데이터를 전달할 수 있다.\
> 이전 예제에서는 name과 age를 각각의 속성으로 따로 전달했다. \
> 이처럼 각 데이터를 개별 props로 지정할 수도 있지만, \
> `전달할 데이터가 많아질수록 props를 하나하나 가정하면 코드가 길어지고 복잡해질 수 있다.`\
> 이럴땐 전달할 데이터를 `하나의 객체나 배열로 묶어 한 번에 전달하는 것이 더 깔끕하고 효율적이다`

```javascript
import User from "./components/User";

exprot default function App(){ // 1)
    const userObj = {
        name: "철수",
        age: 20,
    };
    return <User userObj={userObj} />; // 2)
}
```

1.name 과 age 값을 담은 객체 userObj를 정의한다.

2.userObj 객체를 userObj라는 속성으로 User 컴포넌트에 전달한다.

이처럼 객체 하나를 props를 전달하면 필요한 데이터를 그 안에서 꺼내 사용할 수 있다.\
User컴포넌트에서는 props.userObj로 해당 객체에 접근한다.\
그렇다면 props.userObj의 타입은 무엇일까?? 위처럼 작성하면 userObj 속성에 빨간색 밑줄이 발생한다.\
이부분에 마우스 커서를 가져가면 타입오류라는 메시지가 발생한다.

User.tsx 를 아래와 같이 수정한다.

```javascript
export default function User( props: { userObj: { name: string,  age: number } }){
    return(
        <>
            <p>name : { props.userObj.name }</p>
            <p>age : { props.userObj.age }</p>
        </>
    );
}
```

- 객체 데이터를 자식 컴포넌트에 전달했듯이 **_이벤트 핸들러_** 함수도 props를 통해 자식 컴포넌트에 전달할수 있다.\
  예를 들어 버튼을 클릭했을때 어떤 동작을 실행하고 싶다면 부모 컴포넌트에서 클릭 이벤트 핸들러 함수를 정의하고 자식 컴포넌트에 전달하면된다.

```javascript
import User from "./components/User";

export default function App() {
  const userObj = {
    name: "민우",
    age: 42,
  };
  const clickHandler = () => {
    // 1)
    console.log("클릭했슈");
  };
  return <User userObj={userObj} clickHandler={clickHandler} />; // 2)
}
```

1.clickHandler()는 버튼 클릭 시 실행되는 함수다. 실행되면 콘솔에 clicked를 출력한다.

2.clickHandler() 함수를 clickHandler라는 속성으로 User 컴포넌트에 전달한다.\
이때도 clickHandler 속성에 빨간 밑줄이 생긴다. 이 부분에 마우스를 올리면 오류 메시지가 표시된다.

타입 오류가 날것이다. 그럼 자식 컴포넌트를 아래와 같이 수정해준다.

```javascript
export default function User(
    props: {
            userObj: { name: string; age: number; };
            clickHandler: () => void; // 1)
    }
){
    return(
        <>
            <p>name: { props.userObj.name }</p>
            <p>age: { props.userObj.age }</p>
            <button onClick={ props.clickHandler }>클릭해보슈</button> {/* 2) */}
        </>
    );
}
```

1.clickHandler() 타입은 매개변수도 없고(()) 반환 값도 없는 (void) 함수이므로 () => void로 지정한다.

2.버튼의 onClick 이벤트에 props.clickHandler를 연결한다. 그러면 버튼을 클릭할 때 부모 컴포넌트에서\
정의한 clickHandler() 함수가 실행된다.

- 전달한 props의 타입을 정확히 모를 때는 VSCode의 오류 메시지를 활용하면 매우 유용하다.\
  하지만 오류 메시지가 제대로 작동하려면 다음 두 가지 조건을 만족해야 한다.

  1.**자식 컴포넌트 파일이 존재해야 함** : 컴포넌트 코드가 아예 없으면 VSCode는 props에 대해 검사하지 않는다.\
  따라서 최소한 아래처럼 비어 있는 컴포넌트라도 정의해야 한다.

```javascript
export default function User() {
  return <></>;
}
```

2.**props 매개변수가 없는 상태여야 함** : VSCode는 props 매개변수가 이미 선언되어 있으면 오류 메시지를 표시하지 않는다\
오류 메시지로부터 정확한 props 타입을 추론하려면 props 매개변수를 제거한 상태여야 한다.

## props 객체의 구조 분해 할당과 타입 정의

- 매개변수에서의 구조 분해 할당

props는 단일 객체이므로 부모 컴포넌트에서 속성을 몇십 개 지정해도 결국 **하나의 props** 객체로 전달된다.\
이때 구조 분해 할당을 사용하면 객체의 속성을 더 간단하게 변수에 할당할 수 있다.\
**_구조 분해 할당 (desructuring assignment)_** 은 객체나 배열의 속성을 추출해 변수에 할당하는 자바스크립트 문법이다.\

User 컴포넌트를 구조 분해 할당을 사용하도록 바꾸면 아래와 같다.\
props 객체는 userObj 속성과 clickHandler 속성을 전달하므로 개별 변수로 분해하면 props를 생략하고 더 깔끔하게 작성할수있다.

```javascript
export default function User(
                                { userObj, clickHandler } : { --- 1)
                                    userObj: { name: string, age: number,},
                                    clickHandler: () => void,
                                }

){
    return (
        <>
            <p>name: { userObj.name }</p> --- 2)
            <p>age: { userObj.age }</p>
            <button onClick={ clickHandler } >클릭</button>
        </>
    );
}
```

1.{ userObj, clickHandler }는 객체에서 userObj와 clickHandler라는 두 속성을 꺼내는 구조 분해 할당 구문이다.

2.구조 분해 할당으로 props를 받아오면 jsx에서 props.userObj.name 대신 userObj.name 으로 간결하게 접근할 수 있다.\
userObj 객체의 속성 (name, age)까지 한 번에 구조 분해 할당하면 userObj 도 생략되어 코드가 더 간결해 진다.

```javascript
export default function User(
                                { userObj : { name, age }, clickHandler } : { --- (1)
                                    userObj: { name: string, age: number },
                                    clickHandler: () => void
                                }
){
    return(
        <>
            <p>{ name }</p> --- (2)
            <p>{ age }</p>
            <button onClick={ clickHandler }>완전구조분해할당</button>
        </>
    );
}
```

1.userObj 객체를 다시 구조 분해 할당해서 name과 age값을 꺼낸다.

2.구조 분해 할당은 매개변수에서 바로 처리되므로 userObj.name, userObj.age 대신 name, age만 사용하면 된다.

- 함수 내부에서의 구조 분해 할당
  구조 분해 할당을 꼭 매개변수에서 하지 않아도 된다. props를 그대로 받아 함수 내부에서 분해해도 같은 효과를 얻을 수 있다.

```javascript
export default function User(
                                props: {
                                    userObj: { name:string, age: number },
                                    clickHandler: () => void,
                                }
){
    const {
            userObj: { name, age },
            clickHandler
    } = props;

    return (
        <>
            <p>name : { name }</p>
            <p>age : { age }</p>
            <button onClick={ clickHandler }>클릭</button>
        </>
    );
}
```

이 방식은 props 전체를 일단 받고, 구조 분해 할당을 코드 흐름 중간에서 명확하게 처리하고 싶을 때 유용하다.\
또한 함수 선언부가 짧아서 함수 시그니처를 더 깔끔하게 만들 수 있다.

---

- 타입 정의
  앞의 예제처럼 userObj와 clickHandler tㅗㄱ성을 가진 props의 타입을 한 줄에 모두 작성하면 함수 매개변수의 타입이 너무 길고
  복잡해 보일 수 있다.\
  이럴때는 ***타입스크립트의 인터페이스***를 사용해 props 타입을 따로 정의할 수 있다.
  `interface 대신 type 키워드를 사용해도 동일한 효과를 얻을 수 있다. type 키워드를 사용해 타입을 정의하는 것을 **타입별칭** 이라고 한다`

```javascript
interface UserProps {
    userObj: { name: string, age: number },
    clickHandler: () => void
}

export default function User(props: UserProps){
    const {
        userObj: { name, age },
        clickHandler,
    } = props;
    return(
        <>
            <p>name: { name }</p>
            <p>age: { age }</p>
            <button onClick={ clickHandler }>interface타입정의</button>
        </>
    );
}
```

인터페이스로 타입을 분리하니 props의 타입이 UserProps로 깔끔하게 정리되어 함수 선언부가 훨씬 보기 쉬워졌다.

이렇게 정의한 인터페이스를 리액트에서는 **.d.ts** 파일로 분리할 수 있다.\
그러면 컴포넌트 파일이 깔끕해지고 타입 재사용성도 높아진다.\
이러한 타입 선언 전용 파일은 일반적으로 src/types 폴더에 모아 관리한다.\
이 파일은 따로 임포트하지 않아도 타입을 사용할 수 있다.

```javascript
// src/types/props.d.ts 파일에 인터페이스 별도 정의
interface UserProps {
    userObj: { name: string, age: number },
    clickHandler: () => void
}

// src/components/User.tsx
export default function User(
                                props: UserProps
){
    const {
        userObj: { name, age },
        clickHandler
    } = props;
    return (
        <>
            <p>name : { name }</p>
            <p>age : { age }</p>
            <button onClick={ clickHandler }>타입 별도 정의후</button>
        </>
    );
}
```

## props와 전개 연산자 -> 아하 전개연산자? (spread operator 스프레드 연산자..!!)

현재 App 컴포넌트의 코드는 아래와 같다.

```javascript
import User from "./components/User";

export default function App() {
  const userObj = {
    name: "철수",
    age: 20,
  };
  const clickHandler = () => {
    alert("click");
  };
  return <User userObj={userObj} clickHandler={clickHandler} />;
}
```

여기서는 userObj 객체를 props로 전달할 때 userObj 전체를 하나의 속성으로 설정해 전달힌다.\
따라서 User 컴포넌트에서는 props.userObj로 객체 전체에 접근할 수 있다.

만약 userObj 객체의 속성을 각각 전달하고 싶다면, 전개 연산자(...)를 사용할수있다.\
***전개 연산자***는 객체의 속성을 풀어 해당 위치에 하나하나 나열해주는 역할을 한다.

```javascript
import User from "./components/User";

export default function App() {
  const userObj = {
    name: "철수",
    age: 20,
  };
  const clickHandler = () => {
    alert("클릭이유");
  };
  return <User {...userObj} clickHandler={clickHandler} />;
}
```

위와 같이 작성하면 props에 name, age, clickHandler라는 3개 속성이 개별로 전달되는 효과가 있다.

```javascript
return <User name="철수" age={20} clickHandler={clickHandler} />;
```

자식 컴포넌트에서는 userObj 객체의 속성들이 분리되어 전달되므로 더 이상 props.userObj로 접근할 수 없다. 따라서 개별 속성을 직접 props로 받도록 코드를 아래와 같이 수정한다.

```javascript
// src/types/props.d.ts
interface UserProps {
    name: string,
    age: number,
    clickHandler: () => void
}

// src/components/User.tsx
export default function User(props: UserProps){
    const { name, age, clickHandler } = props;
    return (
        <>
            <p>name: {name}</p>
            <p>age: {age}</p>
            <button onClick={clickHandler}>클릭</button>
        </>
    );
}

```

전개 연산자를 사용하면 코드가 간결해지고 필요한 속성만 선택적으로 전달할 수 있어 편리하다.

## children

> 리액트에서 컴포넌트는 기본적으로 빈 태그 형태 <컴포넌트 /> 로 사용한다.\
> 그런데 컴포넌트를 시작 태그와 종료 태그를 함께 사용하는 형태 <컴포넌트>내용</컴포넌트>로도 사용할수 있다.\
> 이러한 형태를 사용하면 컴포넌트 안에 포함된 내용을 특별한 props 속성으로 취급한다.\
> 리액트에서는 이를 **_children_** 이라고 한다.\
> 예를 들어, User 컴포넌트를 시작 태그와 종료 태그 사이에 내용을 포함하는 방식으로 사용할수 있다.

```javascript
// src/App.tsx

export default function App() {
  return (
    <>
      <User>
        <p>children01</p>
        <p>children02</p>
        <p>children03</p>
      </User>
    </>
  );
}
```

코드에서 <User> 컴포넌트 내부에 작성한 <p> 요소 3개는 모두 User 컴포넌트에 children이라는 속성으로 전달된다.\
리액트에서는 children 이 텍스트, jsx요소, 숫자, 배열 등 다양한 형태가 될 수 있기 때문에 이를 유연하게 처리할 수 있는 **_React.ReactNode_** 타입으로 지정한다.

```javascript
// src/components/User.tsx

export default function User(props: {children: React.ReactNode}){
    return <>{props.children}</>;
}
```

이처럼 props.children 으로 전달받은 콘텐츠를 출력할 수 있다.

아래처럼 구조 분해 할당을 사용하면 코드가 더 간결해진다.

```javascript
// src/components/User.tsx

export default function User({children}: {children: React.ReactNode}){
    return (<>{children}</>);
}
```

> 앞으로는 children 을 사용할 때 구조 분해 할당 방식을 기본적으로 사용한다.

**children** 은 props 객체의 일부이므로 다른 속성과 함께 사용할 수 있다.\
예를들어 User컴포넌트에 title 이라는 속성을 추가로 전달해보자.

```javascript
// src/App.tsx
import User from "./components/User";

export default function App() {
  return (
    <>
      <User title="User component">
        <p>children01</p>
        <p>children02</p>
        <p>children03</p>
      </User>
    </>
  );
}
```

User 컴포넌트는 title 이라는 일반 문자열 속성과 `<p>` 요소 3개로 구성된 children을 함께 전달받는다.\
따라서 User 컴포넌트에서는 두 값을 모두 받을 수 있도록 props 타입을 아래와 같이 설정한다.\
즉, User 컴포넌트에서는 title 속성과 children 속성을 함께 props로 받아 처리하면된다.

```javascript
// src/components/User.tsx

export default function User(
                                {
                                    title,
                                    children
                                } : {
                                    title: string,
                                    children: React.ReactNode
                                }
){
    return (
        <>
            <h1>{title}</h1>
            {children}
        </>
    );
}
```

children은 컴포넌트 태그 사이에 작성된 모든 내용을 하나로 묶어 전달하는 특별한 속성이다.\
내용이 여러 요소로 구성되었어도 리액트는 이를 자동으로 하나의 children 값으로 처리한다.\
`따라서 한 컴포넌트에 children을 2개 이상 따로 지정할 수는 없다.`

> 참고: rel와 key 속성은 props로 전달 불가능
