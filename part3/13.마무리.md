1. 컴포넌트

- 컴포넌트는 ui를 구성하는 독립적이고 재사용 가능한 작은 단위이다.
- 컴포넌트를 사용하면 재사용성, 유지보수성, 로직 분리, 복잡한 상태 관리가 쉬워지고, 결과적으로 애플리케이션의 성능을 최적화할 수 있다.

---

2. 컴포넌트의 종류

- 클래스 컴포넌트 : ES6의 클래스 문법을 사용해 작성하며, Component 클래스를 상속받아 render() 메서드에서 ui를 정의한다.
- 함수형 컴포넌트 : 자바스크립트 함수로 작성하며, jsx를 반환해 ui를 구성한다.\
  문법이 간단하고 가독성이 좋아 현재 가장 많이 사용하는 방식이다.

---

3. 컴포넌트 기초

- 리액트에서 사용 가능한 확장자 .js/.jsx(자바스크립트 기반), .ts/.tsx(타입스크립트 기반)
- 컴포넌트는 주로 함수형 컴포넌트 방식으로 작성한다.
- 리액트 애플리케이션은 여러 컴포넌트를 조합해 구성한다.\
  - 화면에 가장 먼저 랜더링되는 기본 컴포넌트는 App이다.
  - App 컴포넌트 외 나머지 컴포넌트는 src/components 폴더에 파일별로 작성한다.
  - 파일에 작성한 컴포넌트는 export default로 내보내고, 사용할 때는 import로 불러온다.
- 컴포넌트 트리 : 컴포넌트 간 계층 구조를 나타낸다. App 컴포넌트가 최상위 루트 컴포넌트이고, 다른 컴포넌트들을 자식으로 가진다. 데이터는 부모에서 자식으로 전달된다.

---

4. props 객체

- props는 부모 컴포넌트가 자식 컴포넌트에 데이터를 전달할 때 사용하는 객체이다.
- 타입스크립트를 사용할 경우 props의 타입을 정의해야 잘못된 데이터 전달을 방지 할 수 있다.
- 데이터를 속성별로 하나씩 전달하는 대신, 객체 형태로 묶어 한 번에 전달하는 것이 간결하다.
- 함수도 props로 전달할 수 있어 자식 컴포넌트에서 부모의 함수를 실행할 수 있다.
- props는 구조 분해 할당으로 쉽게 꺼내 사용할 수 있다.

5. 이벤트

- 이벤트는 사용자와의 상호자굥을 의미하며, 리액트에서도 이벤트를 통해 상호작용 기능을 구현할 수 있다.
- jsx에서 이벤트를 사용하려면 jsx 요소에 이벤트 속성을 부여하고, 해당 이벤트 핸들러를 연결한다.\

```javascript
// 형식
<JSXElement 이벤트_속성={이벤트_핸들러} />
```

- 이벤트 속성은 jsx 요소에서 이벤트를 처리하기 위해 사용하는 속성으로, 카멜 케이스로 작성한다.
