[표현식은 중괄호 안에서 사용하기]

>{10+20} 이라는 자바스크립트 표현식을 계산
<h1>result : {10 + 20} </h1>
출력 = result : 30

>삼항 연산자 (조건 ? 참일 때 : 거짓일 때)도 사용할 수 있다.
<h1>{10 < 20 ? "10 이 더 작다" : "20이 더 크다"}</h1>
출력 = 10 이 더 작다

>논리 연산자 && 를 사용하면 조건이 참일 때만 jsx 요소를 출력 할 수 있다.
<>
	{10 > 20 && <h1>10이 20보다 크다</h1>}
	{10 < 20 && <h1>10이 20보다 작다</h1>}
</>
출력 = 10이 20보다 작다


[인라인 스타일은 객체로 지정하기]

>html에서는 태그에 직접 style 속성을 지정해 스타일을 적용할 수 있다.
이렇게 태그 안에 직접 스타일을 작성하는 방식을 "인라인 스타일" 이라고 한다.
예를 들어 아래와 같이 style 속성에 문자열을 할당해 <h1>태그의 텍스트 색상을
red 배경 색상을 lightgray로 설정한다.

*html
<h1 style="color: red; background-color: lightgray">Styled Text</h1>

>jsx에서는 style속성에 문자열이 아닌 자바스크립트 객체를 할당한다.
css 속성명은 반드시 "카멜 케이스"로 작성해야 한다.

*jsx
<h1
	style={{
		color: "red",
		backgroundColor: "lightgray",
	}}
>Styled Text</h1>

 
[중괄호 안에 주석 작성하기]

>프로그래밍에서는 코드에 설명을 추가하거나 특정 부분을 임시로 비활성화할 때 
"주석"을 사용한다.
jsx에서도 주석을 사용할수있으며, jsx만의 특별한 작성 규칙이 있다.

jsx에서는 중괄호 안에 /* 주석 내용 */ 형태로 주석을 작성해야 한다.

<>
	{/* 올바른 주석 */}
	<div>올바른 주석 사용 예</div>
</>

html이나 자바스크립트에서 사용하는 주석 방식을 사용하면 웹 브라우저에 그대로 노출된다.

<>
	{/* 올바른 주석 */}
	// 잘못된 주석
	/* 잘못된 주석 */
	<div>잘못된 주석 사용 예</div>
</>

jsx는 내부적으로 html과 자바스크립트를 섞어 사용하므로 태그 밖에 있는 //, /* */ 는
일반 텍스트로 인식된다.

출력 = 
//잘못된 주석 /* 잘못된 주석 */
잘못된 주석 사용 예

윈도우 : Ctrl + /
