[하나의 추트 요소로 반환하기]
>jsx로 작성된 컴포넌트는 반드시 하나의 태그(요소)만 반환해야 한다.

ex)잘못된 코드 : 두 개 이상의 루트 요소 반환

<div>첫번째 영역</div>
<div>두번째 영역</div>

ex)올바른 코드 : 하나의 루트 요소 반환

<div>
	<div>첫번째 영역</div>
	<div>두번째 영역</div>
</div>

 위의 방법은 <div> 같은 불필요한 태그가 추가되기 때문에 실제 html구조가 복잡해질 수 있고,
css로 스타일을 적용할 때 문제가 생길 수 있다.

 이럴때 리액트에서 제공하는 "프래그먼트"는 여러 요소를 하나로 묶어주는 가상의 태그로 실제 html에는 아무것도
랜더링되지 않기 때문에 불필요한 태그를 추가하지 않아도 된다.

*기본 문법
<React.Fragment>
	<div>첫번째 영역</div>
	<div>두번째 영역</div>
</React.Fragment>

 "프래그먼트" 는 단축 문법으로도 쓸 수 있다. <>...</> 형태로 작성하면 더 짧고 읽기 쉬운코드가 된다.
실무에서는 단축 문법을 더 자주 사용한다.

*단축문법
<>
	<div>첫번째 영역</div>
	<div>두번째 영역</div>
</>


[모든 태그 닫기]
>jsx 에서는 <br> <img> 와 같은 html 에서 사용하는 태그와 같이 사옹하면 안된다.
이런 태그를 "빈 태그 (self closing tag)" 라고 한다. => <br> <img> <input> 내용 없이 시작 태그만 존재하는 경우

*jsx 에서는 빈 태그 모두 예외되지 않고 아래 처럼 닫아줘야 한다.
<br /> 
<img />


[태그 속성은 카멜 케이스로 작성하기]
>jsx 는 자바스크립트 문법과 함께 동작하므로 html처럼 속성명을 모두 소문자로 작성하면 오류가 발생할 수 있다.
jsx에서는 속성명을 자바스크립트 변수명 처럼 카멜 케이스로 작성해야 한다.

*카멜케이스 란 여러 단어로 이루어진 이름을 붙일 때 첫 번째 단어는 첫 글자를 소문자, 두 번째 단어부터는 첫 글자를 대문자로 표기.
ex)userInfo, tabIndex, autoPlay, className

*이때 몇 가지 속성이 자바스크립트 예약어와 충돌할 수 있다. 이런 경우 다른 이름으로 대체해야 한다.
가장 대표적인 예가 "class" 이다.
"class"는 자바스크립트에서 클래스를 선언할 때 사용하는 예약어이므로 jsx에서는 "className" 을 사용한다.

>html
<div class="box"></div>

>jsx
<div className="box"></div>


>아래는 html 과 jsx 서로 이름이 다른 속성들을 비교한것이다.
class -> className
for -> htmlFor
contenteditable -> contenEditable
tabindex -> tabIndex
readonly -> readOnly
maxlength -> maxLength
colspan -> colSpan
rowspan -> rowSpan
frameborder -> frameBorder
usemap -> useMap
accesskey -> accessKey
enctype -> encType
accept-charset -> acceptCharset
inputmode -> inputMode
autoplay -> autoPlay
formnovalidate -> formNovalidate

*data 나 aria로 시작하는 속성은 html 표준 규칙을 그대로 따른다.
jsx에서도 하이픈(-) 을 포함한 원래 이름 그대로 사용할 수 있다.


*jsx에서는 잘못된 속성을 사용하면 웹 브라우저의 개발자 콘솔에 경고 메시지가 뜬다.
따라서 모든 속성을 외울 필요는 없고, 콘솔 경고를 잘 확인하는 습관이 중요하다!!
