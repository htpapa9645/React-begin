터미널에서 생성한 "vite-react" 디렉토리로 이동 후

npm create : npm을 사용해 프로젝트 생성 도구를 실행하는 명령어
vite@latest : Vite의 최신 버전을 사용하겠다는 의미.
.(마침표) : 현재 폴더에 프로젝트를 생성하겠다는 뜻.

프로젝트 생성 후 해당 디렉토리에서
>npm install : 프로젝트에 필요한 의존성 패키지 설치
>npm run dev : 개발 서버를 실행해 리액트 애플리케이션을 웹브라우저에서 확인할 수 있게함.

실행에 문제가 없다면 아래와 같이 터미널에 출력됨.

  VITE v8.1.4  ready in 527 ms

  ➜  Local:   http://localhost:5173/       >>>>     브라우저에서 실행해본다.
  ➜  Network: use --host to expose
  ➜  press h + enter to show help

터미널에서 "ctrl+c" 를 하면 서비스가 종료된다.


Tip.위와같이 Vite와 같은 도구를 사용해 프로젝트를 빠르게 시작할 수 있도록 기본 구조와 설정 파일을 자동으로 생성하는 과정을 "스캐폴딩" 이라고한다.
이를 통해 복잡한 환경 설정을 직접 하지 않고도 명령어 한 줄로 리액트 애플리케이션의 기본 틀을 빠르게 만들 수 있다.
