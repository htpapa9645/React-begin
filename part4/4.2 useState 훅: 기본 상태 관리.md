# useState 훅 : 기본 상태 관리

리액트에서는 상태를 관리할 때 훅을 사용한다.\
**훅(hook)** 이란 함수형 컴포넌트에서 상태(state)와 생명주기(lifecycle)를 쉽게 관리할 수 있도록 도와주는,
리액트에서 제공하는 특별한 함수다.\
훅은 2018년 10월 25일 ReactConf에서 처음 소개되었으며, 2019년 2월 6일에 출시한 리액트 16.8 부터 정식도입되었다.

가장 대표적인 훅으로는 \*\*useState와 useReducer가 있다.

## useState 훅의 기본 문법

useState 훅은 [이전_상태(값)] 상태*변경*함수] 형태의 배열을 반환하는 함수다.\
이 배열을 구조 분해 할당 하면 컴포넌트 내부에서 상태를 저장하고 변경할 수 있는 2개의 변수를 선언할 수 있다.\
두 변수를 사용해 컴포넌트의 상태를 효과적으로 관리할 수 있다.\
상태 값이 변경되면 리액트는 해당 컴포넌트를 자동으로 리랜더링 하여 ui를 새로운 상태로 업데이트한다.

useState 훅은 아래와 같은 형식으로 사용한다.

```javascript
const [state, setState] = useState < Type > initialState;
```

- state : 상태 값을 저장하는 변수로, 보통 **상태 변수** 라고 부른다. state라는 이름은 단순한 예일 뿐이며, 관리하려는 상태의 성격에 맞게 자유롭게 이름 지어도 된다. 예를 들어 숫자를 관리한다면 count, 문자열이면 text와 같이 이름을 짓는다.
