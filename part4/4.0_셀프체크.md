#### 아래 조건에 맞는 리액트 애플리케이션을 구현해보자.

- [아이템 추가] 버튼을 만든다
- [아이템 추가] 버튼을 클릭하면 '사과, 바나나, 오렌지'를 1개씩 추가한다.
- 아이템 3개를 추가하면 더 이상 추가할 수 없다.
- 추가한 아이템은 배열로 관리한다.
- 추가한 아이템을 \<ul> 과 \<li> 태그를 사용해 목록으로 출력한다.
- \<li> 태그의 구성은 추가한 아이템과 [삭제] 버튼이다.
- [삭제] 버튼을 클릭하면 아이템을 삭제한다.
- 삭제한 아이템은 다시 추가할 수 있다.
- 구현할 때 useReducer 훅을 사용한다.

#### 풀이

##### 1. 리듀서 함수 작성하기

useReducer 훅을 사용하려면 가장 먼저 리듀서 함수를 정의해야 한다. 리듀서 함수는 2개의 매개변수, 즉 상태와 액션을 받아 새로운 상태를 반환한다. 이때 상태와 액션 모두 타입을 지정해주는 것이 좋다.

조건은 아래와 같다.

- 사과, 바나나, 오렌지를 순서대로 한 번씩만 추가할 수 있다.
- 3개의 아이템이 모두 추가되면 더 이상 추가할 수 없다.
- 추가한 아이템이라도 삭제하면 다시 추가할 수 있다.
- 아이템의 추가와 삭제는 상태를 변경하는 행위이며, 이를 리듀서 함수로 처리한다.

리듀서 함수구현

```javascript
// src/types/cart.d.ts
type Item = { --- 1
  item: string[];
  availableItems: ["사과", "바나나", "오렌지"];
};

type ReducerAction = --- 2
  | { type: "ADD_ITEM" }
  | { type: "REMOVE_ITEM"; index: number };

```

1. 추가 가능한 아이템 목록(availableItems)과 실제로 추가된 아이템(items)을 구분할 수 있도록 상태를 객체 형태로 정의하고 타입을 지정.

2. 액션 객체는 일반적으로 type과 payload 속성으로 구성된다. 여기서는 아이템을 추가할 때는 payload가 필요없지만, 삭제할 때는 삭제할 인덱스가 필요하다. 따라서 액션마다 다른 payload 타입을 가질 수 있도록 유니언 타입을 활용해 액션 타입을 정의한다.

```javascript
// src/reducer/itemReducer
export function itemReducer(state: Item, action: ReducerAction) { --- 1
  switch (action.type) { --- 2
    case "ADD_ITEM": --- 3
      // availableItems 에서 아이템을 하나씩 가져와 추가
      if (state.items.length < 3) {
        const newItem = state.availableItems.filter(
          (item) => !state.items.includes(item),
        )[0];
        return {
          ...state,
          items: [...state.items, newItem],
        };
      }
      return state;
    case "REMOVE_ITEM": --- 4
      return {
        ...state,
        items: state.items.filter((_, index) => index !== action.index),
      };
    default:
      return state;
  }
}

```

1. 리듀서 함수는 상태와 액션을 매개변수로 받아 새로운 상태를 반환한다. 앞에서 정의한 상태와 액션 타입을 사용해 타입 안전성을 확보한다.

2. 액션의 type 속성을 기준으로 ADD_ITEM 과 REMOVE_ITEM 두 가지 동작을 switch 문으로 분기 처리한다.

3. items 배열의 길이가 3보다 작을 경우 availableItems 에서 아직 추가되지 않은 아이템을 순서대로 하나씩 선택해 items 배열에 추가한다. 이미 추가된 아이템은 중복 추가되지 않도록 한다.

4. 삭제한 아이템의 인덱스를 액션 객체를 통해 전달받아 items 배열에서 해당 인덱스의 아이템만 제거한다. 이 로직은 availableItems 에는 영향을 주지 않고, items 배열에만 적용된다.

##### 2. 컴포넌트 화면 구성하기

리듀서 함수를 사용해 컴포넌트 로직을 아래와 같이 작성.

```javascript
// src/app.tsx
import { useReducer } from "react";
import { itemReducer } from "./reducer/itemReducer"; --- 1

export default function App() {
  const initialState: Item = { --- 2
    items: [],
    availableItems: ["사과", "바나나", "오렌지"],
  };

  const [state, dispatch] = useReducer(itemReducer, initialState); --- 3

  const handleAddItem = () => { --- 4
    dispatch({ type: "ADD_ITEM" });
  };

  const handleRemoveItem = (index: number) => { --- 5
    dispatch({ type: "REMOVE_ITEM", index });
  };

  return (
    <div>
        <h1>아이템 목록</h1>
        <button onClick={handleAddItem} disabled={state.items.length === 3}>아이템 추가</button> --- 6
        <ul>
            {state.items.map((item, index) => ( --- 7
                <li key={index}>
                    {index}:{item} <button onClick={() => handleRemoveItem(index)}>삭제</button>
                </li>
            ))}
        </ul>
    </div>
  );
}

```

1. 리듀서 함수를 컴포넌트에서 사용할 수 있도록 불러온다.

2. 상태의 초깃값을 정의한다. 이 값은 useReducer 훅의 초기 상태로 사용한다.

3. useReducer 훅을 사용해 상태와 액션 발생 함수를 생성한다. 첫 번째 인자는 리듀서 함수(1), 두번째 인자는 초깃값(2) 다.

4. 아이템을 추가하는 이벤트 핸들러를 정의한다. dispatch({ type : 'ADD_ITEM' }) 을 호출해 삭제할 인덱스를 전달한다. 리듀서 함수는 type 값이 REMOVE_ITEM 인 로직을 실행한다.

5. 아이템을 삭제하는 이벤트 핸들러를 정의한다. dispatch({ type : 'REMOVE_ITEM', index }) 를 호출해 삭제할 인덱스를 전달한다. 리듀서 함수는 type 값이 'REMOVE_ITEM' 인 로직을 실행한다.

6. 추가 버튼은 items 배열의 길이가 3 이상일 경우 비활성화 되도록 disabled 속성을 설정한다.

7. 추가된 아이템은 \<ul> 태그로 출력되며, 각 \<li> 요소에는 해당 아이템 이름과 함께 [삭제] 버튼이 표시된다. 삭제 버튼은 삭제 이벤트 핸들러와 연결되어 해당 아이템을 목록에서 제거한다.
