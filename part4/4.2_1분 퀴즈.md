### 07. 다음 코드에서 오류가 발생하는 이유는 무엇인가요?

```javascript
export default function App() {
  const clickHandler = () => {
    const [count, setCount] = useState(0);
    setCount(count + 1);
  };
  return <button onClick={clickHandler}>클릭</button>;
}
```

1. 상태 값이 숫자형이라서
2. 상태 변경 함수를 사용하지 않아서
3. useState 훅의 초깃값을 지정하지 않아서
4. useState 훅을 이벤트 핸들러 내부에서 호출해서
